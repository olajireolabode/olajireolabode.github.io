# Olasubomi Olabode — Developer Portfolio

Welcome to my personal portfolio!

I’m a software engineering student who enjoys building useful things, solving problems, and turning ideas into working projects. I also want to create technology that can help people and communities. This portfolio is a snapshot of what I’m learning, what I’m building, and how I’m growing as a developer.

## Design Inspiration

I’m a huge Football Manager fan, and I’ve been playing the game for around 10 years. I’m pretty addicted to it, so using its player-profile style for my portfolio felt natural.

I like how Football Manager presents information through profiles, attributes, roles, and strengths. I wanted to bring that familiar layout into my software engineering journey and create something that reflects both my personality and my interest in technology.

I kept the near-black theme, charcoal panels, and subtle purple accents to make the design feel modern, focused, and easy to navigate while staying true to the Football Manager inspiration.

## How I Work

I learn by building, experimenting, testing, and improving things step by step. I’m still exploring which area of software engineering I want to specialize in, so I’m open to learning across different parts of development.

I also use AI tools as part of my workflow. I use them to brainstorm and plan ideas, learn unfamiliar concepts, debug problems, work through code, and improve documentation. I see AI as a helpful assistant, not a substitute for understanding the work. I still need to review the suggestions, test the results, and take responsibility for the final product.

## Running the Portfolio Locally

1. Download or clone the portfolio files.
2. Keep `index.html`, `style.css`, and `olajire.js` in the same folder.
3. Keep any required images or other assets in their expected folders.
4. Open `index.html` in your browser, or use a local development tool such as Live Server in Visual Studio Code.
